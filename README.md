# شكون؟ — Shkoun
**لعبة تخمين ذكية للأشخاص موجهة للعائلات والأصدقاء والمجموعات الخاصة**

تطبيق ولعبة تخمين ذكية مستوحاة من ألعاب التعرف على الشخصيات، لكنها مبنية بمحرك استنتاج مخصص (Question & Deduction Engine) يعمل **دون اتصال بالإنترنت بالكامل (100% Offline)**، وبدون أي اعتماد على خوادم أو APIs أو ذكاء اصطناعي سحابي خارجي.

---

## 🌟 الميزات الرئيسية

1. **محرك استنتاج مبني على تقليل الإنتروبيا (Information Gain / Entropy Reduction)**:
   - يحلل مجموعة المرشحين الحالية ويختار السؤال الأكثر قدرة على تقسيم الاحتمالات بشكل متوازن.
   - **منحنى التجربة المتدرج (Pacing Curve)**:
     - **مرحلة الاستكشاف (Discovery)**: أسئلة ديموغرافية عامة (الجنس، الفئات العمرية) لتفادي حرق الشخصية في أول سؤالين.
     - **مرحلة التضييق (Narrowing)**: أسئلة المهنة، مكان الإقامة، الحالة العائلية، والخصائص المشتركة.
     - **مرحلة الحسم (Reveal)**: أسئلة شديدة التمييز والعلاقات المباشرة لكشف الشخصية بدقة.
   - **معاملة ذكية للإجابة "لا أعرف" (Unknown)**: لا تستبعد المرشحين، بل تعيد توجيه المحرك نحو محاور أخرى مستقلة.
   - **عدم إنهاء اللعبة عند التخمين الخاطئ**: إذا قال اللاعب "لا، ليس هذا الشخص"، يستمر المحرك مع المرشحين المتبقين بسلاسة.

2. **وضع المبتكر المستقل (Creator Mode)**:
   - إنشاء وإدارة مجموعات متعددة (عائلتي، أصدقاء العمل، فريق الكرة، إلخ).
   - إضافة الأشخاص بحقول مرنة: الاسم، صورة اختيارية، الجنس، سنة الميلاد/العمر، المدينة، والمهنة.
   - **نظام الخصائص المخصصة (Custom Facts)**: إضافة حقائق مرنة مثل: *"يلعب كرة القدم"*، *"يحب الشخشوخة"*، *"معروف بالهدوء"*.
   - **نظام العلاقات الذكي والاستنتاج التلقائي (Smart Inferred Relationships)**:
     - إدخال العلاقة من جهة واحدة يكفي: النظام يستنتج تلقائياً العلاقات العكسية (أب ↔ ابن، زوج ↔ زوجة، إخوة عبر الأب أو الأم المشتركين).
     - تمييز داخلي واضح بين العلاقات المُدخلة يدوياً والعلاقات المستنتجة برمجياً.

3. **لوحة فحص سلامة البيانات (Data Health Dashboard)**:
   - كشف فوري للتعارضات المنطقية: (شخص والد لنفسه، علاقات نسب دائرية، تعارض أعمار بين الوالد والابن، أو تكرار أسماء).
   - نسبة اكتمال الملفات الشخصية وإحصائيات العلاقات والخصائص.

4. **تصدير واستيراد البيانات (Export / Import)**:
   - تصدير قاعدة بيانات أي مجموعة كملف `JSON`.
   - استيراد آمن مع فحص توافق البيانات ومطابقة البنية، وخياري الدمج (Merge) كـ مجموعة جديدة أو الاستبدال (Replace).

5. **أصوات وتأثيرات بدون إنترنت (100% Synthetic Web Audio)**:
   - مؤثرات صوتية مبنية بالكامل باستخدام Web Audio API (توليد ذبذبات صوتية حية) بدون الحاجة لأي ملفات MP3 خارجية.

6. **جاهزية Android عبر Capacitor و GitHub Actions**:
   - إعدادات Gradle كاملة ومستقرة، تدعم التثبيت المباشر كـ Android APK.

## 📁 بنية المشروع (Architecture)

```
shkoun/
├── .github/workflows/
│   └── android.yml                # بناء تلقائي لـ Android APK عبر GitHub Actions
├── android/                       # مشروع Android متكامل لـ Capacitor
│   ├── app/
│   │   ├── build.gradle
│   │   └── src/main/AndroidManifest.xml
│   ├── build.gradle
│   └── settings.gradle
├── src/
│   ├── core/                      # محرك اللعبة والاستنتاج
│   │   ├── deduction/             # محرك الانتقاء وتقليل الإنتروبيا (DeductionEngine)
│   │   ├── inference/             # الاستنتاج الذكي للعلاقات (RelationshipInference)
│   │   ├── question-engine/       # توليد الأسئلة الديناميكية (QuestionPool)
│   │   ├── validation/            # فحص التعارضات وصحة البيانات (DataValidator & Health)
│   │   └── __tests__/             # اختبارات المحرك الأساسية (Vitest)
│   ├── data/                      # طبقة البيانات والتخزين
│   │   ├── models/                # النماذج والواجهات البرمجية (Types)
│   │   ├── repository/            # مستودع البيانات (DatabaseService)
│   │   └── storage/               # التخزين المحلي غير المتصل (StorageDriver)
│   ├── game/                      # شاشات اللعب
│   │   └── screens/               # بدء اللعب، طرح الأسئلة، التخمين، وشاشة النصر
│   ├── creator/                   # وضع المبتكر (لوحة التحكم وإدارة الأشخاص)
│   │   └── screens/               # تعديل الشخص، العلاقات، فحص الصحة، الاستيراد/التصدير
│   └── shared/                    # عناصر ومرافق مشتركة
│       ├── image/                 # ضغط الصور محلياً (ImageCompressor)
│       ├── sound/                 # مولد الأصوات التخليقي (AudioService)
│       └── ui/                    # مكونات الواجهة (Header, Modal, Avatar)
├── capacitor.config.ts            # إعدادات Capacitor
├── package.json
└── vite.config.ts
```

## 🚀 طريقة التشغيل محلياً (Development)

### 1. تثبيت الحزم:
```bash
npm install
```

### 2. تشغيل خادم التطوير:
```bash
npm run dev
```
افتح المتصفح على: `http://localhost:3000`

### 3. تشغيل الاختبارات:
```bash
npm run test
```

### 4. بناء نسخة الإنتاج للويب:
```bash
npm run build
```

## 📱 بناء تطبيق Android APK

### الخيار 1: البناء التلقائي عبر GitHub Actions (الأسهل)
1. ارفع المشروع إلى مستودع GitHub الخاص بك:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of Shkoun"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/shkoun.git
   git push -u origin main
   ```
2. افتح تبويب **Actions** في GitHub.
3. سيبدأ مسار العمل **Build Android APK** تلقائياً.
4. بعد اكتمال البناء (خلال 3-4 دقائق)، حمّل ملف **`Shkoun-Debug-APK`** من قسم **Artifacts** وثبّته مباشرة على هاتفك.

### الخيار 2: البناء محلياً على جهازك
يتطلب وجود Android Studio و Java JDK 17:
```bash
# 1. بناء ملفات الويب ومزامنتها مع مجلد Android
npm run build
npx cap sync android

# 2. بناء APK باستخدام Gradle
cd android
./gradlew assembleDebug
```
ستجد ملف APK الناتج في المسار:
`android/app/build/outputs/apk/debug/app-debug.apk`
